  • Visual Timer

    Chrome extension

    A free classroom visual timer that floats over any page, including full-screen Google Slides and Canva. Themes, sounds and shortcuts.

    Get it on Chrome for Visual Timer (opens in a new tab) Learn more about Visual Timer

  • WebInk

    Chrome extension

    Draw, highlight and annotate on web pages, then save a screenshot. WebInk makes no network requests.

    Get it on Chrome for WebInk (opens in a new tab) Learn more about WebInk
    • Privacy policy for WebInk

  • PolyRead

    Chrome extension

    Reads text aloud in English, Spanish and French with word-by-word highlighting, to support multilingual learners.

    Get it on Chrome for PolyRead (opens in a new tab) Learn more about PolyRead
    • Privacy policy for PolyRead

  • Bell Schedule

    Chrome extension

    Rings a bell and announces each class period out loud. A simple replacement for the old speaking clock.

    Get it on Chrome for Bell Schedule (opens in a new tab) Learn more about Bell Schedule
    • Privacy policy for Bell Schedule
